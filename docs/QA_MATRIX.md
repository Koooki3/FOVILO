# Verification matrix

Run locally on Windows with Node 24.13.1 and Playwright Chrome for Testing 145.0.7632.6. The fixture routes desktop YouTube requests to synthetic local HTML and uses a generated silent media resource. It exercises the built MV3 extension in Chromium.

| Check | Scope |
| --- | --- |
| `npm run typecheck` | Strict TypeScript |
| `npm run lint` | MV3 declaration and permission allowlist |
| `npm test` | Canonical route parsing and timestamp links |
| `npm run test:browser` | Home → Watch SPA, clipboard, simulated ad entry/exit (clipboard unchanged during the ad and time links restored afterward), stale media handoff, repeat events, history back, late/replaced Watch root and anchor, native node and comment draft preservation, and global and per-feature popup toggles |
| Live signed-out YouTube Watch | Passed one page on 2026-11-12. The copy action reported success, the control detached on global off, and the same native video element continued from 2.06 s to 6.34 s without pausing. [Preview and environment](RELEASE_MATERIALS.md#watch-development-preview) |
| `npm run test:live` | Passed on 2026-11-12. Live signed-out Home → Search → Watch → Search, browser Back/Forward, native fullscreen enter/exit, and global off after reload. This check needs network access and depends on the public search result, so it runs separately from fixture CI. |
| Live playlist and caption controls | Passed on 2026-11-12 via `npm run test:live`. Selected *Sintel* in the native playlist after *Big Buck Bunny*. The two clipboard links matched the respective video IDs and the 4 s and 12 s seek positions. The native caption button changed its pressed state with one FOVILO control mounted. [Public playlist](https://www.youtube.com/playlist?list=PLav47HAVZMjnTFVZL-aImCQIC0uLZtNCz) |
| Live autoplay and track selection | The native subtitle menu reported English after selecting the track. A separate start near the end of *Sintel* let YouTube advance on its own. The next episode had one FOVILO control and the clipboard link matched its video ID and 6 s seek position. |
| Chromium extension manager | The fixture disables and re-enables the extension via `chrome://extensions/`. After reload, the native heading remains visible with the extension disabled, and one Watch control returns after re-enabling and reloading. |
| Keyboard and clipboard recovery | The Chromium fixture reaches **Copy time link** via Tab and activates it via Space with default clipboard settings. With clipboard writes blocked by the fixture's Permissions Policy, Enter exposes and selects the exact manual URL. Keyboard **Return to YouTube** moves focus to the native video heading. The next Tab returns to the native sequence and removes the temporary heading tabindex. A fresh signed-out YouTube profile also passed Enter-to-copy and native focus restoration. |
| 200% zoom and live region semantics | The fixture applied Chromium tab zoom to a 640 px viewport and verified the resulting 320 CSS px layout. The controls, feedback and selectable manual link stayed inside the panel. On live YouTube at 200% zoom (640 CSS px), the panel stayed in view, keyboard copy succeeded and focus returned to the native title. Chromium's accessibility tree exposed the empty Watch and popup status regions as polite live regions, and the Watch region retained the same node after feedback. Manual screen-reader announcement remains pending. [Resize text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) · [Status messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html) |
| Rendered caption probe | Inconclusive on 2026-11-12. Two fresh signed-out Chromium profiles played *Sintel* from the 128 s link, one without FOVILO and one with FOVILO. Both received HTTP 200 from the caption endpoint and advanced past 143 s, but neither exposed a visible caption segment during the 15 s observation window. |

Slow samples overlap renderer long tasks. Broader device and permission coverage remains open. |

Light, dark and restored metadata crops were inspected from `work/everyday/` at a 1280×800 viewport. |

At 200% zoom, the live page may use a different recommendations container, in which case Focus is absent and the other Watch controls remain available. |
