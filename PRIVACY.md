# FOVILO development privacy notice

[简体中文](#简体中文)

FOVILO runs on desktop `www.youtube.com`. It uses the page URL and native controls to identify the current surface. On request, it reads the current video position and writes a timestamped YouTube URL to the clipboard. If the write is denied, it displays the URL for manual copying.

The extension stores its global, Home, Watch and Search switches in browser-local extension storage. Density, disclosure and recent command choices remain in the current page session. FOVILO makes no extension-initiated network requests and sends no telemetry. YouTube and the browser continue to apply their own privacy policies to their services.

The browser manages shortcut assignments. Removing FOVILO clears its extension-local settings. Closing or reloading YouTube clears the in-memory session state.

## 简体中文

FOVILO 在桌面版 `www.youtube.com` 上运行。它用当前页面地址和原生控件识别页面。用户主动复制时间链接时，扩展读取当前播放位置，将带时间参数的 YouTube 链接写入剪贴板。若写入失败，会显示可手动复制的链接。

扩展只在浏览器本地保存全局、首页、播放页和搜索页开关。密度、控件展开状态和最近命令只留在当前页面会话。FOVILO 自身没有网络请求或遥测。YouTube 和浏览器的服务适用各自的隐私政策。

快捷键分配由浏览器管理。移除扩展可清除扩展本地设置，关闭或刷新 YouTube 页面可清除会话状态。
